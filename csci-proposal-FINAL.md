# Surviving the Bottleneck: Do AI Models Trained on AI Output Converge to a Common Endpoint?

**Sakxam Shrestha — CSCI, Assignment 02: Project Proposal**

## Introduction to the Research Topic

My project focuses on *model collapse* — the degradation that occurs when AI models are trained on data produced by other AI models. Shumailov et al. (2024) showed that a model repeatedly retrained on its own output first loses rare cases and eventually loses variety altogether. This problem is important because the open internet is filling with AI-generated content, so future models will increasingly be trained this way whether or not anyone intends it, and it is scientifically interesting because two established literatures make opposite predictions about the same process: model-collapse research expects degradation, while iterated learning research in cognitive science expects the reverse, holding that a narrow transmission "bottleneck" between generations *creates* structure because only simple, learnable patterns survive being handed down repeatedly. My main goal is to determine which outcome actually occurs in chains of neural networks and, more usefully, what controls the answer. Griffiths and Kalish (2007) identified the deciding condition: a chain of learners forgets its starting data and settles into whatever the learners are naturally biased toward, but only if each learner keeps a range of possible answers rather than committing to one, since learners that commit never fully forget where they began. A neural network trained by standard methods commits to one answer, and whether this distinction — established for idealized learners and confirmed with human participants — holds for real neural networks appears to be untested. I have already built the experiment and run a pilot, which produced three results. Nothing organizes itself: agreement with the original model falls steadily toward chance in every setting tested. How much data passes between generations matters far more than how training is tuned: when each generation sees only 128 of 4,096 examples, usable output categories collapse from all 50 down to a handful within 25 generations. Most importantly, chains descending from the *same* starting model end up using overlapping categories at 2.94 times the overlap expected by chance, while chains from *different* starting models overlap at only 1.13 times chance, which is indistinguishable from random. **Where a chain ends up is determined by where it started, not by the network's design** — exactly the behavior predicted for a learner that commits to one answer. My research question is therefore: **does this commit-versus-keep-options-open distinction govern where neural model chains come to rest, and can convergence be restored by making the network keep a range of solutions instead of one?** Through this project I expect to learn whether a well-established cognitive-science result transfers to deep networks, and to produce a measured answer either way. I want to be clear that the underlying phenomena are not new discoveries — collapse under repeated retraining is proven (Mobahi et al., 2020), the bottleneck is this literature's founding variable (Kirby, 2001), and Jarvis et al. (2026) tracked the process in mathematically simplified networks — so my contribution is narrower and I state it as such: those results hold where the learner's built-in bias can be calculated on paper, and I test them where it cannot.

## Detailed Plan to Complete the Project

**Data, datasets, and resources.** The core experiments use a small synthetic dataset built for the purpose, chosen for measurement validity rather than convenience. Each input combines five features of ten values each, giving 4,096 examples across 50 balanced categories that are reused across every generation. This construction is what makes the study measurable: the true structure is known by design, chance performance is exactly 1/50, and the overlap expected between random category sets can be calculated exactly, giving a precise baseline against which every headline number is compared. Web-scraped datasets provide none of these guarantees. A second dataset, EMNIST-balanced, supplies a real-data check, because its 47 balanced categories are directly comparable to my synthetic 50.

**Programming languages, frameworks, and libraries.** The project is written in Python, using PyTorch for model definition and training, NumPy and SciPy for the statistical analysis, and Matplotlib for figures. Experiments are configuration-driven, and every generation writes its measurements to a log file so that each figure in the final report can be regenerated from a saved run rather than a one-off script.

**System architecture and major components.** The central component is a chain harness. Generation zero is trained on the original labels; every later generation is a fresh neural network of roughly 92,000 parameters that never sees those labels and learns only from the previous generation's predictions on a limited sample of size B, which is the transmission bottleneck. Around this sit three further components: a metrics module that records agreement between generations, surviving category counts, and internal-representation statistics; an analysis module that computes overlap between chains against a calculated random baseline; and a plotting module.

**Algorithms and methods.** The chain itself is built on knowledge distillation, in which each generation learns from the previous model's predicted probabilities rather than from true labels. The main method I will vary is how each network settles on an answer: standard training, which commits to a single solution and which I have already measured; a noisy training procedure that draws from a range of solutions instead of one; and an ensemble of networks whose combined output approximates the same effect. I will also implement the same chain procedure using a simple linear model whose behavior can be calculated exactly on paper.

**Experiments and comparisons.** The central experiment measures how much the surviving categories overlap between chains started from different original models, compared against the calculated random baseline, since this is what separates genuine convergence from chains that merely die off in arbitrary directions. This is run once per training method, giving the primary comparison. Two control comparisons follow: the linear model, which tests whether any apparent structure is just the ordinary shrinkage that repeated retraining produces automatically, and the EMNIST replication, which tests whether the findings are an artifact of synthetic data. The pilot used five starting models, so the full study uses at least ten per condition, with the main measurement and its thresholds committed to a timestamped record before the experiments run. Feasibility has been measured rather than assumed: one synthetic generation trains in 1.6 seconds on a laptop, and a benchmark at EMNIST's exact size gave 8.7 seconds per generation on the laptop's graphics processor, putting the second arm near 1.3 hours. Google Colab Pro is available if a larger version proves worthwhile, but the design deliberately does not require rented computing power.

**How I will evaluate success.** Success is defined as a completed, reproducible measurement with a clear baseline, not as confirmation of my hypothesis. Concretely, the project succeeds if overlap is reported for every training method with error bars across at least ten starting models, the pilot's central contrast is replicated at larger scale, the category-collapse curve is characterized, and the comparison against the linear model is reported whichever way it comes out. A result showing that no training method produces convergence would be a complete finding rather than a failure, since it would establish that neural chains stay tied to their origins in a way idealized learners do not.

**Final deliverables.** I expect to produce four things: an open-source experimental toolkit with per-generation logging and the overlap analysis; a figure set covering overlap by training method, the same-origin versus different-origin contrast, and the category-collapse curves; a written report; and a short methodological note documenting that Centered Kernel Alignment (Kornblith et al., 2019), a standard similarity measure and my originally proposed main metric, reported 0.950 similarity between consecutive generations at a point when agreement with the original model had already fallen to 0.188. This blindness was documented by Davari et al. (2023); I confirm that it persists across long chains, which is a warning worth passing on to anyone instrumenting a similar experiment.
